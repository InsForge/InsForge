## 获取帮助

在 [InsForge Discord](https://discord.com/invite/DvBtaEc9Jz) 中提问——这是联系团队和其他开发者最快的方式。

## 报告 Bug 或请求功能

使用 CLI `feedback` 命令报告 InsForge 侧的问题——Bug（包括文档与实际行为不一致）、缺失的功能或开发体验上的摩擦。这用于反馈 InsForge 本身的问题（后端、某个 SDK、CLI、Agent 技能或文档），而不是您正在构建的应用。提交前，邮箱、令牌、密钥和用户名会在本地被脱敏处理，且无需登录。

```bash
# 交互式：会提示补齐仍需要的必填字段
npx @insforge/cli feedback

# 非交互式（Agent / CI）
npx @insforge/cli feedback \
  --type bug \
  --component sdk \
  --language js \
  --title "verifyOtp rejects a valid code" \
  --detail "Steps, expected vs actual, and anything else useful"
```

- `--type` — `bug`、`feature-request`、`friction` 或 `other`
- `--component` — `backend`、`sdk`、`cli`、`skills`、`docs` 或 `other`
- `--language` — 当 `--component sdk` 时必填（例如 `js`、`python`、`swift`、`kotlin`、`rest-api`）
- `--title` 和 `--detail` — 摘要和描述（使用 `--file <path>` 从文件加载描述内容）
- `--severity` — `blocker`、`major` 或 `minor`（默认为 `minor`）

`--type`、`--component`、`--title` 和 `--detail` 为必填项；不带这些参数运行命令时会进入交互式提示。传入 `--json` 可获得结构化结果。
