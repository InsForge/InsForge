## 常见问题

<AccordionGroup>
  <Accordion title="Pro 上的超额费用是多少？">
    Pro 包含慷慨的限额，然后仅对超出限额的使用量计费：

    | 资源 | 超过包含金额的费率 |
    |---|---|
    | 月度活跃用户 | $0.00325 / MAU |
    | 数据库 | $0.125 / GB |
    | 带宽 | $0.09 / GB |
    | 文件存储 | $0.021 / GB |
    | 边缘函数调用 | $0.01 / 1,000 次调用 |
  </Accordion>

  <Accordion title="自定义计算计费如何工作？">
    免费计划每月包括**默认规格上的 120 小时自定义计算**。在专业版上，自定义计算是**按使用情况计费**：运行您自己的容器和长时间运行的工作负载，并为您使用的内容付费。每个月还附带**$10 的 InsForge 计算积分**来抵消它。
  </Accordion>

  <Accordion title="用完 $10 计算积分后会发生什么？">
    不会停止任何操作 — 每月 $10 的 InsForge 计算积分（在专业版上）涵盖前 $10 的计算，超过该金额计算继续按使用量付费。
  </Accordion>

  <Accordion title="如何查看当前用量？限额何时重置？">
    通过 CLI 打印您的组织在当前计费周期内的用量：

    ```bash
    npx @insforge/cli usage
    # 指定某个组织：
    npx @insforge/cli usage --org-id your-org-id
    # 机器可读格式：
    npx @insforge/cli usage --json
    ```

    它会显示您的套餐，以及计入上述限额的各项总量（AI 积分、月度活跃用户、数据库、带宽/出网流量、文件存储、边缘函数调用），随后按项目细分数据库、存储和出网流量。

    消耗类计数（AI 积分、月度活跃用户、带宽/出网流量、边缘函数调用）按计费周期统计，并在每个新周期开始时从零重新计算。在专业版上，该周期遵循您订阅的每月计费周期；在免费版上，限额按月计算。数据库和文件存储等容量类指标不是按周期计数的 — 它们反映您当前存储的内容，删除数据后会随之下降。
  </Accordion>
</AccordionGroup>
