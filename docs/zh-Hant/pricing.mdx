InsForge 對原型和副專案有免費套餐，對生產有付費計畫。此頁面鏡像 [定價頁面](https://insforge.dev/pricing)。

## 常見問題

<AccordionGroup>
  <Accordion title="Pro 上的超額費用是多少？">
    Pro 包含慷慨的限額，然後僅對超出限額的使用量計費：

    | 資源 | 超過包含金額的費率 |
    |---|---|
    | 月度活躍使用者 | $0.00325 / MAU |
    | 資料庫 | $0.125 / GB |
    | 頻寬 | $0.09 / GB |
    | 檔案儲存空間 | $0.021 / GB |
    | 邊緣函數呼叫 | $0.01 / 1,000 次呼叫 |
  </Accordion>

  <Accordion title="自訂運算計費如何工作？">
    免費計畫每月包括**預設規格上的 120 小時自訂運算**。在專業版上，自訂運算是**按使用情況計費**：執行您自己的容器和長期執行的工作負載，並為您使用的內容付費。每個月還附帶**$10 的 InsForge 運算積分**來抵消它。
  </Accordion>

  <Accordion title="用完 $10 運算積分後會發生什麼？">
    不會停止任何操作 — 每月 $10 的 InsForge 運算積分（在專業版上）涵蓋前 $10 的運算，超過該金額運算繼續按使用量付費。
  </Accordion>

  <Accordion title="如何查看目前用量？限額何時重置？">
    透過 CLI 印出您的組織在目前計費週期內的用量：

    ```bash
    npx @insforge/cli usage
    # 指定某個組織：
    npx @insforge/cli usage --org-id your-org-id
    # 機器可讀格式：
    npx @insforge/cli usage --json
    ```

    它會顯示您的方案，以及計入上述限額的各項總量（AI 積分、月度活躍使用者、資料庫、頻寬/出網流量、檔案儲存空間、邊緣函數呼叫），接著按專案細分資料庫、儲存空間和出網流量。

    消耗類計數（AI 積分、月度活躍使用者、頻寬/出網流量、邊緣函數呼叫）按計費週期統計，並在每個新週期開始時從零重新計算。在專業版上，該週期遵循您訂閱的每月計費週期；在免費版上，限額按月計算。資料庫和檔案儲存空間等容量類指標不是按週期計數的 — 它們反映您目前儲存的內容，刪除資料後會隨之下降。
  </Accordion>
</AccordionGroup>
